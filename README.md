# Kalkulus – matematikkhjelp.no

Læreboka **Kalkulus** på [matematikkhjelp.no/kalkulus/](https://matematikkhjelp.no/kalkulus/), på ingeniørnivå: inverse og elementære funksjoner, grenseverdier og kontinuitet, derivasjon og anvendelser, integrasjon, integrasjonsteknikker og anvendelser, følger og rekker, Taylorpolynomer og differensiallikninger. Funksjoner av flere variabler står i læreboka [Flervariabel kalkulus og PDE-er](https://github.com/Realfagsambassaden/flervariabel-kalkulus).

- `kapitler/` – én mappe per kapittel, én `.qmd`-fil per side. Hver side har `tema:` og `undertema:` øverst (temakartet er `matematikkhjelp/tema.yml` i [Plattform](https://github.com/Realfagsambassaden/Plattform)).
- `figurer/` – TikZ-figurer. `python3 figurer/lag.py` lager `bilder/figurer/*.svg`.
- Sider med `plassholder: true` er ikke skrevet ennå.

Stoffet er skrevet med egne ord, egne eksempler og egne figurer.

Les [AGENTS.md](AGENTS.md) og [BIDRA.md](BIDRA.md) før du bidrar. Alt på `main` publiseres automatisk.
